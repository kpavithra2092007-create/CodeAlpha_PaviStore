# Pavi Store - E-commerce Website

A full-stack e-commerce web application built with Python and Django as part of my Full Stack Development virtual internship at CodeAlpha.

## Features
- Product listing with prices and descriptions
- Add to cart
- Shopping cart page
- Place order
- User registration and login

## Tech Stack
- Python
- Django
- HTML
- SQLite (Django default database)

## How to Run
1. Clone this repository
2. Install Django: `pip install django`
3. Run migrations: `python manage.py migrate`
4. Start the server: `python manage.py runserver`
5. Open http://127.0.0.1:8000 in your browser

## What I Learned
- Building a full-stack web app with Django
- Working with models, views, URLs and templates
- Handling user registration and login
- Building a shopping cart and order flow
